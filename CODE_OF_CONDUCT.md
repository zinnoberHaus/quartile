# Community code of conduct

Participants should communicate respectfully, welcome different experience levels, give actionable feedback, credit others' work, and respect privacy. Critique proposals and code without attacking people.

Harassment, threats, discriminatory abuse, unwanted sexual attention, disclosure of private information, impersonation, and deliberate disruption are unacceptable. This policy applies to project issues, pull requests, discussions, and other spaces when representing the project.

The repository owner is initially responsible for moderation. For a concern that can safely be discussed publicly, open an issue without exposing personal information. For a sensitive concern, request a private contact in an issue without incident details; a dedicated private conduct channel has not yet been established. GitHub's reporting and blocking tools remain available for platform abuse. The project currently has no independent appeals body or alternate moderator for reports involving the owner.

Moderation may include removing content, a warning, temporary restrictions, or removal from project participation, proportionate to severity and recurrence. The moderator should explain the applicable rule and action where practical, protect private information, and consider corrections or an appeal through the same contact channel. Threats and severe harassment may justify immediate restrictions.

This is an original project policy, not a claim of adopting a third-party covenant or having a staffed moderation service.
