Charts from code blocks

Fictional sample data. This file has no build step: it includes one script and writes ```quartile blocks as ordinary <pre><code> markup, which is what Markdown renderers such as MkDocs, Hugo, Jekyll and dbt docs produce. Switch to dark mode: the charts follow the page.

Revenue by region

The rows come from sales.csv next to this page, loaded once and shared.

data sales
src: sales.csv
revenue.format: currency USD

barlist sum(revenue) by region
title: Revenue by region, Q3 2026
select: true
data: sales
